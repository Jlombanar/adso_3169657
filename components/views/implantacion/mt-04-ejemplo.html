3. Introducción, objetivo y alcance

Helados Mimos es un sistema para que una heladería publique su carta de productos. Lo forman una app móvil Android hecha en Flutter y una API REST en Node.js con Express, desplegada en Render, que guarda los datos en Supabase y las imágenes en Cloudinary.

Objetivo del documento: describir la arquitectura, los datos, la API y la configuración para que un desarrollador pueda instalar, mantener y ampliar el sistema. Alcance: backend, app móvil y servicios externos. No incluye el uso de las pantallas (ver manual de usuario).

9. Documentación de la API

URL base: https://[su-servicio].onrender.com/api · Formato: JSON · Autenticación: encabezado Authorization: Bearer <token>.

MétodoRutaTokenDescripción
POST/registerNoCrea un usuario.
POST/loginNoValida correo y contraseña; responde el token.
POST/auth/googleNoInicio de sesión con la cuenta de Google.
GET/heladosNoLista la carta.
POST/heladosAdminCrea un helado (multipart/form-data con la foto).
PUT/helados/:idAdminEdita un helado; la foto es opcional.
DELETE/helados/:idAdminElimina un helado.

Ejemplo de un endpoint documentado completo:

POST /api/login
Petición (JSON): { "email": "admin@heladosmimos.com", "password": "********" } Respuesta 200: { "token": "eyJhbGciOi...", "usuario": { "id": 1, "nombre": "Ana", "rol": "admin" } } Errores: 400 Faltan campos → { "mensaje": "Correo y contraseña son obligatorios" } 401 Credenciales incorrectas → { "mensaje": "Correo o contraseña incorrectos" } 500 Error del servidor

10. Seguridad

  • Autenticación: la API entrega un JWT firmado con JWT_SECRET; el middleware verificarToken lo valida en las rutas protegidas.
  • Roles: solo el rol admin puede crear, editar y eliminar helados.
  • Contraseñas: se guardan cifradas con bcrypt.
  • Base de datos: RLS activo; el backend usa la llave secret y la app no tiene llaves de Supabase.
  • Firma de la app: el AAB se firma con upload-keystore.jks, que no está en el repositorio (ver Firma del AAB).

13. Mantenimiento

Cómo agregar una ruta nueva (ejemplo: marcar un helado como agotado):

  1. Agregar la columna disponible (bool) a la tabla helados en Supabase.
  2. Crear la función en backend/controllers/heladoController.js.
  3. Registrar la ruta PATCH /api/helados/:id/disponible en routes/, protegida con verificarToken.
  4. Agregar el campo a lib/models/producto_model.dart y el método en producto_service.dart.
  5. Actualizar las secciones 8 y 9 de este manual y subir la versión del documento.
Error conocidoCausaSolución
La primera petición tarda cerca de un minutoRender Free duerme el servicio tras 15 min sin uso.Monitor de UptimeRobot o plan pago.
Las fotos desaparecen tras redesplegarEl disco de Render es efímero.Guardar siempre en Cloudinary.
401 en rutas de administradorToken vencido o ausente.Volver a iniciar sesión; revisar el encabezado Authorization.

Logs: Render → servicio → Logs. Base de datos: Supabase → Logs.
