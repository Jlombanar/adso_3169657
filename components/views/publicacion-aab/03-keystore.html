2.3Generación del keystore (.jks)

Google Play solo acepta AAB firmados con una llave propia (upload key). Se crea una sola vez por app.

💻 macOS / Linux
keytool -genkey -v -keystore ~/upload-keystore.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias upload
💻 Windows (PowerShell)
keytool -genkey -v -keystore $env:USERPROFILE\upload-keystore.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias upload
¿Sale "command not found: keytool"? Usa el de Android Studio
macOS
"/Applications/Android Studio.app/Contents/jbr/Contents/Home/bin/keytool" -genkey -v -keystore ~/upload-keystore.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias upload
Windows
& "C:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkey -v -keystore $env:USERPROFILE\upload-keystore.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias upload

En PowerShell el & del inicio es obligatorio: sin él, una ruta entre comillas no se ejecuta.

⚠️
Errores frecuentes en este paso
• No escribas "Y": lo que va entre corchetes, como [SENA], es el valor por defecto; Enter lo reutiliza.
• El país no es un código postal: C=9525 ❌ → C=CO ✅.
• Si te equivocas, responde no a la confirmación. Si la llave ya se creó, bórrala y repite: rm ~/upload-keystore.jks (Mac) o Remove-Item $env:USERPROFILE\upload-keystore.jks (Windows).
Salida esperada
Generando par de claves RSA de 2.048 bits para certificado autofirmado (SHA384withRSA) con una validez de 10.000 días para: CN=JIMMY ALEXANDER LOMBANA RIVERA, OU=SENA, O=SENA, L=GARZON, ST=HUILA, C=CO [Almacenando /Users/.../upload-keystore.jks]
💾
Advertencia crítica: respaldo y fuera de Git
• Guarda upload-keystore.jks y su contraseña en dos lugares seguros (USB y gestor de contraseñas o drive personal). Si se pierden, tendrás que pedirle a Google en Play Console que restablezca la upload key, y mientras tanto no podrás publicar actualizaciones.
• El .jks nunca se sube a GitHub: lo recomendado es crearlo fuera del proyecto (en ~) y bloquearlo en .gitignore. Si prefieres tenerlo dentro de android/, mira la opción 2 de la sección 2.4.
💻 macOS / Linux: bloquear llaves en Git (desde la raíz del proyecto)
echo "key.properties" >> android/.gitignore echo "**/*.jks" >> android/.gitignore echo "env.json" >> .gitignore
💻 Windows (PowerShell)
Add-Content android\.gitignore "key.properties" Add-Content android\.gitignore "**/*.jks" Add-Content .gitignore "env.json"
⚠️
En Windows no uses echo >>
En Windows PowerShell 5.1, >> escribe en UTF-16 y Git no reconoce esas líneas: el .jks quedaría sin protección sin que lo notes. Add-Content escribe bien. Compruébalo con git status: no debe aparecer key.properties.
