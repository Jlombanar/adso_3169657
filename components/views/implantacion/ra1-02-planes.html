RA 01 · PLAN DE INSTALACIÓN

El paso a paso de la puesta en producción

El plan de instalación ordena las tareas, dice quién las hace, cuánto tardan y cómo se comprueba cada una. Este es el que vamos a ejecutar en el RA 02.

#ActividadResponsableTiempoCómo se verifica
1Crear o verificar cuentas: GitHub, Render, Supabase, Cloudinary, UptimeRobot.Líder del equipo30 minTodos los integrantes entran a cada panel.
2Preparar el backend: script start, process.env.PORT, .gitignore, push a GitHub.Backend30 mingit status limpio y .env fuera del repositorio.
3Crear el Web Service en Render y registrar las variables de entorno (paso a paso con capturas).Backend30 minEstado Live y logs sin errores.
4Probar la API con Postman (listar, login, crear con foto).Pruebas30 minTodas las peticiones responden 200 o 201.

RA 01 · EVIDENCIA

Entregable: Plan de implantación de Helados Mimos

Un documento (PDF) por equipo, con normas APA o ICONTEC, que reúna todo lo trabajado en este resultado.

1
Portada e introducción: proyecto, equipo, ficha y propósito del documento.
2
Plataforma tecnológica: tipo de servidor, sistema operativo, proveedores y por qué se eligieron. Expliquen dónde vive cada parte: la base de datos en Supabase (ya en línea, no requiere migración), el código en GitHub y las fotos en Cloudinary.
3
Requisitos mínimos: la tabla de verificación con la columna ¿Cumple? diligenciada.
4
Plan de instalación y contingencia: actividades, responsables, tiempos y verificación.
🧠 Cierre del RA 01
  • Planear es decidir antes: plataforma, requisitos e instalación.
  • Cada parte de Helados Mimos vive en un servicio en la nube: Supabase, GitHub y Cloudinary.
  • Con el plan listo, el siguiente paso es ejecutarlo: desplegar en Render (RA 02).
