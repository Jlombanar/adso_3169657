Panel Administrativo
Helados Mimos

Desde los modelos de usuario y producto hasta las pantallas del administrador y la carta del cliente, conectados al backend (Node + Express + Supabase + Cloudinary). Todo el código es el del proyecto real.

📦 7 librerías
🧱 2 modelos · 4 servicios
🧩 4 componentes
📄 2 páginas
🔄 Carta conectada al backend
🎯 Objetivo
Construir el panel administrativo de Helados Mimos: menú lateral (Drawer) con los datos reales del admin, formulario de producto en bottom sheet con foto (galería, cámara, arrastrar y soltar, y encuadre), el servicio que crea/edita/elimina en el backend con el token del admin, la pantalla que lista los productos, y la carta del cliente leyendo esos mismos productos del servidor.

UserService: registro y login
Registro, login con correo y login con Google. Si el servidor responde con error, se lanza una Exception con el mensaje del backend para mostrarlo en pantalla.

Después del login se guardan en el dispositivo el token, el nombre, el correo y el rol. El panel los lee para mostrar los datos del admin y enviar el token al backend. Si el rol es admin, va directo al panel.

AdminProductService: crear, editar y eliminar
Estas rutas están protegidas en el backend, así que se envía el token en el header Authorization: Bearer <token>. La foto viaja como multipart/form-data en el campo imagen (el que espera Multer) y con su tipo real, porque Cloudinary rechaza archivos que no reconoce como imagen.

dart · código completoimport 'dart:convert'; import 'dart:io'; import 'package:http/http.dart' as http; import 'package:http_parser/http_parser.dart'; import 'package:shared_preferences/shared_preferences.dart'; import 'api_config.dart'; // Operaciones del panel administrativo sobre /helados (requieren token de admin) class AdminProductService { static Future<String?> _obtenerToken() async { final prefs = await SharedPreferences.getInstance(); return prefs.getString('jwt_token'); } static String _mensajeError(http.Response response) { try { final data = jsonDecode(response.body); return (data['message'] ?? data['error'] ?? 'Error del servidor (código ${response.statusCode})') .toString(); } catch (_) { return 'El servidor no respondió con JSON válido (código ${response.statusCode}). ' 'Verifica que el backend esté corriendo y que la URL en api_config.dart sea correcta.'; } } // Arma la parte "imagen" de la petición multipart con Content-Type explícito: // Cloudinary rechaza el archivo si no se reconoce como imagen static Future<http.MultipartFile> _archivoImagen(File imagen) async { final bytes = await imagen.readAsBytes(); final ext = imagen.path.split('.').last.toLowerCase(); final subtipo = switch (ext) { 'png' => 'png', 'webp' => 'webp', 'avif' => 'avif', _ => 'jpeg', }; return http.MultipartFile.fromBytes( 'imagen', // Nombre del campo que espera Multer en el backend bytes, contentType: MediaType('image', subtipo), filename: 'producto_${DateTime.now().millisecondsSinceEpoch}.${subtipo == 'jpeg' ? 'jpg' : subtipo}', ); } static Future<void> crearProducto({ required String nombre, required String descripcion, required double precio, required File imagen, }) async { final token = await _obtenerToken(); final request = http.MultipartRequest('POST', Uri.parse('${ApiConfig.baseUrl}/helados')); request.headers['Authorization'] = 'Bearer $token'; request.fields['nombre'] = nombre; request.fields['descripcion'] = descripcion; request.fields['precio'] = precio.toString(); request.files.add(await _archivoImagen(imagen)); final response = await http.Response.fromStream(await request.send()); if (response.statusCode != 201) { throw Exception(_mensajeError(response)); } } static Future<void> actualizarProducto({ required String id, required String nombre, required String descripcion, required double precio, File? imagen, // opcional: solo si el admin cambió la foto }) async { final token = await _obtenerToken(); final request = http.MultipartRequest('PUT', Uri.parse('${ApiConfig.baseUrl}/helados/$id')); request.headers['Authorization'] = 'Bearer $token'; request.fields['nombre'] = nombre; request.fields['descripcion'] = descripcion; request.fields['precio'] = precio.toString(); if (imagen != null) { request.files.add(await _archivoImagen(imagen)); } final response = await http.Response.fromStream(await request.send()); if (response.statusCode != 200) { throw Exception(_mensajeError(response)); } } static Future<void> eliminarProducto(String id) async { final token = await _obtenerToken(); final response = await http.delete( Uri.parse('${ApiConfig.baseUrl}/helados/$id'), headers: {'Authorization': 'Bearer $token'}, ); if (response.statusCode != 200) { throw Exception(_mensajeError(response)); } } }

AdminImageSelector: recuadro de la foto
El recuadro donde va la foto del producto. Permite:
  • Tocar para elegir de la galería o tomar con la cámara.
  • Arrastrar y soltar una imagen desde el escritorio (app en macOS / Windows / Linux) con DropTarget.
  • Emulador de Android: al soltar una foto sobre el emulador, este la copia a Descargas; el componente la detecta y la pone sola en el recuadro (solo en modo debug).
  • Acomodar la foto: arrastrarla dentro del recuadro y pellizcar para hacer zoom. Al guardar se sube el recorte tal como quedó.

Editar con foto nueva
Para que editar también cambie la foto, el controlador debe leer req.file (la URL que deja Cloudinary). Además, solo actualiza los campos permitidos y responde 404 si el helado no existe.

javascript// editar export const editar = async (req, res) => { try { const { id } = req.params; const { nombre, descripcion, precio, stock, categoria, sabor } = req.body; // Solo se actualizan los campos que llegan en la petición const actualizaciones = {}; if (nombre !== undefined) actualizaciones.nombre = nombre; if (descripcion !== undefined) actualizaciones.descripcion = descripcion; if (precio !== undefined) actualizaciones.precio = Number(precio); if (stock !== undefined) actualizaciones.stock = Number(stock); if (categoria !== undefined) actualizaciones.categoria = categoria; if (sabor !== undefined) actualizaciones.sabor = sabor; // Si se envió una imagen nueva, Cloudinary deja la URL en req.file.path if (req.file) actualizaciones.imagen_url = req.file.path; if (Object.keys(actualizaciones).length === 0) { return res.status(400).json({ error: 'No se enviaron datos para actualizar' }); } const { data, error } = await actualizarHelado(id, actualizaciones); if (error) return res.status(500).json({ error: 'Error al actualizar' }); if (!data || data.length === 0) return res.status(404).json({ error: 'Helado no encontrado' }); return res.status(200).json({ message: 'Actualizado', helado: data[0] }); } catch (error) { return res.status(500).json({ error: error.message }); } };
